# N-Bank
N-Bank is a simple online banking system written in Java.
The project demonstrates basic Object-Oriented Programming (OOP) concepts.

## Features
- Create users
- Create bank accounts
- Deposit money
- Withdraw money
- Transfer money
- Store users and accounts
- Work with transactions

## Project Structure
src/main/java/com.bank/
├── model/
│   ├── Account.java
│   ├── Transaction.java
│   └── User.java
│
├── service/
│   ├── AccountService.java
│   └── UserService.java
│
├── storage/
│   ├── AccountStorage.java
│   └── UserStorage.java
│
└── Main.java

## Technologies
- Java
- Object-Oriented Programming
- Git

## How to Run
- Open the project in IntelliJ IDEA.
- Open Main.java.
- Run the main() method.
